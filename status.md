### Этап 2 — индивидуальное задание (вариант 7)

Структура каталога `lab19_variant07/`:

```text
main.py          # argparse: --input, --output, --method, --bpm, --hop, --threshold и т.д.
audioio.py       # чтение/запись, norm to [-1,1], mono, clip + warning
processing.py    # spectral flux, onset detection, tempo via autocorrelation
metrics.py       # onset error ms, BPM error, precision/recall/F1 по атакам
plots.py         # осциллограммы, спектры, спектрограммы, flux, envelope ACF
synth.py         # детерминированный синтез метрономов 100/120/140 BPM
audioutils.py    # модуль из приложения А task.md
README.md
sounds/
results/
```

Обязательные части:

- **Часть А:** параметры сигнала, пик/RMS/пик-фактор, перегрузка, обзорные графики, описание составляющих.
- **Часть Б:** spectral flux + детектор атак + оценка темпа по АКФ огибающей; WAV/графики; метрики.
- **Часть В:** два ключевых параметра (например, `hop`/`nper` и `threshold`; при необходимости `median_filter`), по 3 значения каждый; ≥3 сигналов/уровней; `experiments.csv`; графики; рекомендации.

Требования к программе: `--help`, понятные ошибки, ненулевой exit code, clip перед записью, воспроизводимость seed, защита от больших файлов.
