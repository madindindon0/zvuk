# Лабораторная работа 19, вариант 7

**Тема:** ритмичный музыкальный фрагмент / метроном. Обнаружение атак по
спектральному потоку, оценка темпа по АКФ огибающей. Показатели:
погрешность времени атак (мс), темп BPM и его погрешность (%).

## Состав проекта

| Файл | Назначение |
| --- | --- |
| `main.py` | CLI на `argparse`, оркестрация частей А/Б/В, `summary.json` |
| `audioio.py` | Чтение WAV любого PCM-формата, сведение в моно, Levels, запись с `np.clip` |
| `processing.py` | Spectral flux, детектор атак, оценка темпа по АКФ |
| `metrics.py` | Погрешности атак и BPM, precision/recall/F1, CSV/JSON |
| `plots.py` | Осциллограммы, спектр, спектрограмма, flux, АКФ, графики экспериментов |
| `synth.py` | Детерминированный синтез метрономов 100/120/140 BPM и эталонов |
| `audioutils.py` | Адаптация приложения А с аннотациями и docstring |
| `sounds/` | Синтетические и внешний CC0-метроном, `references.json` |
| `results/` | WAV, PNG, CSV, JSON, TXT (все выходные данные) |

## Установка и запуск

Использовать Python из корневого `.venv`:

```bash
cd lab19_variant07
../.venv/bin/python main.py --help
../.venv/bin/python main.py --method all --input sounds --output results \
    --create-synth --hop-ms 10 --window-ms 40 --threshold 1.5 \
    --min-distance-ms 200 --seed 42
```

Отдельные части:

```bash
../.venv/bin/python main.py --method analyze --input sounds/metronome_120bpm.wav
../.venv/bin/python main.py --method onset_tempo --input sounds --output results
../.venv/bin/python main.py --method experiments --input sounds --output results
```

### Параметры CLI

- `--input` — файл или каталог с аудиофайлами;
- `--output` — каталог результатов;
- `--method` — `analyze`, `onset_tempo`, `experiments`, `all`;
- `--bpm` — эталонный темп, если для файла нет разметки;
- `--hop-ms`, `--window-ms` — шаг и длина окна STA;
- `--threshold` — множитель адаптивного порога (0 < порог ≤ 20);
- `--min-distance-ms` — минимальная дистанция между атаками;
- `--seed` — seed всех случайных процессов;
- `--max-seconds` — защита от файлов длиннее 10 минут (по умолчанию 600);
- `--create-synth` — создать сигналы в `sounds/` и скопировать CC0-файл.

Полный список с описаниями: `../.venv/bin/python main.py --help`.

## Методы (кратко)

1. **Чтение (часть А).** Soundfile/libsndfile возвращает `float64`;
   при использовании `scipy.io.wavfile` целочисленные отсчёты делятся
   на полную шкалу. Для 24-битных значений, хранящихся в младших 24 битах
   `int32`, делитель `2**23`; в libsndfile/scipy значения лево-сдвинуты,
   поэтому применяется делитель `2**31`. Многоканальные файлы сводятся
   в моно, запись WAV выполняется через `np.clip` с предупреждением
   при перегрузке.
2. **Spectral flux.** Для кадров STA с окном Ханна:
   `F[k] = Σ_m max(|X[k,m]| − |X[k−1,m]|, 0)`, затем усреднение
   скользящим окном. Положительная разница подавляет затухания.
3. **Атаки.** Порог `T = max(γ·Q75(F), 0.02·max(F))`, локальные максимумы
   с минимальной дистанцией. Время атаки равно центру кадра флюкса;
   нулевая подложка по краям позволяет обнаружить атаку в `t=0`.
4. **Темп.** Импульсная огибающая атак сглаживается, затем
   `r[τ] = Σ_n e[n]e[n+τ] / Σ_n e[n]²`. Ищется максимум в 60–200 BPM;
   среди заметных пиков (≥60 % максимума) выбирается самый короткий
   период, что устраняет октавную ошибку 60 вместо 120 BPM.
5. **Метрики.** Атаки сопоставляются с эталоном с допуском 50 мс;
   считаются средняя/медианная/максимальная ошибка, precision/recall/F1
   и ошибка BPM в процентах. Для синтетики дополнительно вычисляется
   SNR реконструкции метронома по обнаруженным атакам.

## Результаты

- `results/<name>_info.txt` — параметры сигнала (часть А);
- `results/<name>_overview.png` — осциллограмма, фрагмент, спектр, спектрограмма;
- `results/<name>_flux.png` — spectral flux с атаками и порогом;
- `results/<name>_acf.png` — АКФ с найденным периодом;
- `results/<name>_detected.wav` — сигнал с отметками атак (обработанный WAV);
- `results/<name>_comparison.png` — до/после при одинаковых масштабах осей;
- `results/<name>_metrics.json`, `results/<name>_onsets.csv` — метрики и разметка;
- `results/experiments.csv` — 189 экспериментов (3 сигнала BPM + внешний
  + 3 зашумлённых состояния × 3×3×3 параметров);
- `results/plots/*.png` — зависимости метрик от параметров;
- `results/summary.json` — стабильная структура для генератора отчёта.

АЧХ фильтра не строится: в варианте 7 нет фильтра, вместо этого обязательно
построены и объяснены графики flux и АКФ (см. `RESULT.md`).

## Обработка ошибок

Ненулевой код возврата и понятное сообщение получают: отсутствующий файл,
неподдерживаемый формат, пустой каталог, нулевые/отрицательные параметры,
порог вне `(0, 20]`, слишком короткий сигнал и файл длиннее `--max-seconds`.

Воспроизводимость обеспечивается фиксированным `seed=42`; повторный
запуск с теми же параметрами даёт одинаковые WAV и метрики.
