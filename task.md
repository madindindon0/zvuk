## 1. ТЕОРЕТИЧЕСКИЕ ОСНОВЫ ЦИФРОВОЙ ОБРАБОТКИ ЗВУКА
В   этой   главе   изложены   минимальные   теоретические   сведения,
необходимые для сознательного выполнения лабораторной работы. Основное
внимание уделено физическому смыслу операций и тем параметрам, которые
студент будет выбирать в программах: частоте дискретизации, разрядности,
длине окна, порядку фильтра и частоте среза.
1.1. Звук как физическое явление и как сигнал
Звук   —   это   механические   колебания   упругой   среды   (воздуха,   воды,
твёрдого тела), распространяющиеся в виде волны. В воздухе звуковая волна
представляет собой чередование сжатий и разрежений, то есть отклонений
давления от атмосферного. Скорость звука в воздухе при температуре 20 °C
составляет   около   343   м/с.   Микрофон   преобразует   изменение   давления   в
изменение   электрического   напряжения;   зависимость   этого   напряжения   от
времени и называют звуковым сигналом x(t).
Простейший   звуковой   сигнал   —   гармоническое   колебание   x(t)   =
A·sin(2πft + φ), где A — амплитуда, f — частота в герцах (число периодов в
секунду), φ — начальная фаза в радианах. Период T = 1/f — время одного
колебания   (рис.   1,   а).   Человек   слышит   колебания   с   частотами
приблизительно от 20 Гц до 20 кГц; с возрастом верхняя граница снижается
до   12–16   кГц.   Речь   занимает   в   основном   полосу   100–8000   Гц,   а   для   её
разборчивости   достаточно   полосы   300–3400   Гц,   которую   и   передаёт
классический телефонный канал.

Рис. 1. Гармонический сигнал и сложение гармоник: а — тон с амплитудой A и периодом
T; б — сумма трёх гармоник 100, 200 и 300 Гц с амплитудами 1, 1/2 и 1/3
Реальные   звуки   не   являются   чистыми   тонами.   Звук   музыкального
инструмента или гласный звук речи — это сумма основного тона с частотой
F0 и гармоник (обертонов) с кратными частотами 2F0, 3F0 и т. д. (рис. 1, б).
Соотношение амплитуд гармоник определяет тембр: именно поэтому нота
«ля» первой октавы (440 Гц) по-разному звучит на скрипке и на фортепиано.
Шумы   (шипение,   шелест,   глухие   согласные)   не   имеют   периодической
структуры,   и   их   энергия   распределена   в   широкой   полосе   частот.   Это
различие — фундамент многих алгоритмов анализа: периодические сигналы
дают в спектре отдельные линии, шумовые — сплошной фон.
Диапазон   звуковых   давлений,   воспринимаемых   ухом,   огромен:   от
порога слышимости 20 мкПа до болевого порога около 20 Па, то есть в
миллион раз. Поэтому уровни звука выражают в логарифмических единицах
— децибелах. Уровень звукового давления L = 20·lg(p / p0) дБ, где p0 = 20
мкПа. В цифровой обработке за опорное значение принимают максимально
возможную амплитуду (полную шкалу), и уровень обозначают дБFS: L =
20·lg(|x| / 1) для сигнала, нормированного к диапазону от −1 до 1. Сигнал на
полной   шкале   имеет   уровень   0   дБFS,   все   остальные   —   отрицательные
значения. Уменьшение амплитуды вдвое соответствует −6 дБ, в десять раз —
−20 дБ. Для отношений мощностей используется формула 10·lg(P1 / P2),
поскольку мощность пропорциональна квадрату амплитуды.
1.2. Дискретизация, квантование и наложение спектров
Аналоговый сигнал непрерывен и по времени, и по значению. Чтобы
обработать     его     на     компьютере,     выполняют     аналого-цифровое
преобразование, которое включает две операции: дискретизацию по времени
и квантование по уровню (рис. 2, а).
## 6

Методические указания к лабораторной работе No 19
Дискретизация     —     это     замена     непрерывного     сигнала
последовательностью   его   значений   (отсчётов),   взятых   через   равные
промежутки времени T: x[n] = x(nT), n = 0, 1, 2, ... Величина fд = 1/T
называется  частотой  дискретизации.  Например,  при  fд  =  16  кГц  за  одну
секунду берётся 16 000 отсчётов, а интервал между ними равен 62,5 мкс.
Теорема Котельникова (в зарубежной литературе — теорема Найквиста
— Шеннона) утверждает: сигнал, спектр которого ограничен частотой fmax,
может   быть   точно   восстановлен   по   своим   отсчётам,   если   fд   >   2·fmax.
Половину частоты дискретизации fд/2 называют частотой Найквиста. Если в
сигнале   присутствуют   составляющие   выше   частоты   Найквиста,   они
«отражаются»   в   низкочастотную   область   и   становятся   неотличимы   от
настоящих   низкочастотных   составляющих.   Это   явление   называют
наложением спектров, или алиасингом (aliasing). На рис. 2, б синусоида 7 Гц,
дискретизированная   с   частотой   8   Гц,   даёт   ровно   те   же   отсчёты,   что   и
синусоида 1 Гц (с обратным знаком): по цифровым данным эти сигналы
различить   невозможно.   Составляющая   с   частотой   f   после   дискретизации
проявляется на частоте |f − m·fд|, где m — ближайшее к f/fд целое число.
Рис. 2. Аналого-цифровое преобразование: а — дискретизация и квантование сигнала (8
уровней, 3 бита); б — наложение спектров: синусоида 7 Гц при fд = 8 Гц неотличима от
синусоиды 1 Гц
Наложение необратимо: после дискретизации его уже нельзя устранить.
Поэтому   перед   аналого-цифровым   преобразователем   всегда   ставят
аналоговый   фильтр   нижних   частот   (антиалиасинговый   фильтр),   а   при
программном   понижении   частоты   дискретизации   (децимации)   сигнал
сначала пропускают через цифровой фильтр нижних частот и только затем
прореживают. Этот эффект исследуется в примере 3.3.
Квантование   —   это   округление   значения   каждого   отсчёта   до
ближайшего из конечного набора уровней. При разрядности b бит число
уровней равно 2^b: 256 уровней при 8 битах, 65 536 уровней при 16 битах.

Методические указания к лабораторной работе No 19
Разность между исходным и квантованным значением называют ошибкой
(шумом) квантования. Для синусоиды, занимающей всю шкалу, отношение
сигнал/шум квантования определяется формулой SNR ≈ 6,02·b + 1,76 дБ, то
есть каждый дополнительный бит улучшает SNR примерно на 6 дБ. Для 16
бит это около 98 дБ, что перекрывает динамический диапазон большинства
реальных записей. Если сигнал занимает не всю шкалу, SNR уменьшается на
величину   «запаса»:   у   сигнала   с   амплитудой   0,5   он   на   6   дБ   меньше
расчётного.
Типовые сочетания частоты дискретизации и разрядности приведены в

1.3. Цифровое представление и форматы звуковых файлов
В программе звуковой сигнал хранится как одномерный массив отсчётов
(моно) или двумерный массив размера «число отсчётов × число каналов»
(стерео   и   многоканальный   звук).   Сам   по   себе   массив   не   содержит
информации о частоте дискретизации, поэтому её всегда передают вместе с
данными — отдельной переменной fs. Длительность сигнала равна N / fs
секунд, а момент времени n-го отсчёта — n / fs.
Отсчёты хранятся либо как целые числа, либо как числа с плавающей
точкой. Формат PCM (pulse-code modulation, импульсно-кодовая модуляция)
с 16-битными целыми со знаком (тип int16, диапазон от −32 768 до 32 767) —
самый распространённый. Для вычислений сигнал переводят в вещественный
тип float64 и нормируют к диапазону от −1 до 1, деля на 32 768. Перед
записью   в   16-битный   файл   выполняют   обратное   преобразование:
ограничивают значения диапазоном [−1, 1] (операция clip) и умножают на 32

1.4. Временные характеристики сигнала и кадровая обработка
Осциллограмма   —   график   зависимости   амплитуды   от   времени   —
первое, на что смотрят при анализе звука. По ней видны паузы, громкие и
тихие   участки,   перегрузка   (срезанные   вершины),   щелчки.   Числовые
характеристики сигнала во временной области:
– пиковое значение max|x[n]| — показывает запас до перегрузки;
–   среднеквадратичное   значение   (RMS)   √(Σx[n]²/N)   —   характеризует
мощность и субъективную громкость сигнала; для синусоиды RMS = A/√2,
что соответствует −3 дБ относительно пика;
– пик-фактор — отношение пика к RMS; для синусоиды он равен √2 ≈
1,41, для речи — 4–10, для сильно сжатой музыки — 2–4;
– энергия E = Σx[n]² и средняя мощность E/N;
– частота переходов через ноль (zero-crossing rate, ZCR) — доля пар
соседних отсчётов с разными знаками; у шумов и глухих согласных она
высока, у гласных и тональных звуков — низка.
Звуковые сигналы нестационарны: их свойства меняются во времени.
Слово длится доли секунды, а за это время сменяется несколько звуков.
Поэтому характеристики вычисляют не по всему сигналу, а по коротким
фрагментам — кадрам (frames). Типичные параметры для речи: длина кадра
20–40 мс (на этом интервале речевой сигнал можно считать стационарным),

1.5. Спектральный анализ: ДПФ, БПФ и оконные функции
Согласно теории Фурье, любой сигнал конечной длительности можно
представить   суммой   гармонических   составляющих.   Спектр   показывает,
какие   частоты   и   с   какими   амплитудами   присутствуют   в   сигнале.   Для
цифрового   сигнала   из   N   отсчётов   вычисляют   дискретное   преобразование
Фурье (ДПФ):
X[k] = Σ x[n]·exp(−j·2π·k·n / N), n = 0 ... N − 1, k = 0 ... N − 1.
Коэффициент   X[k]   —   комплексное   число:   его   модуль   |X[k]|
пропорционален   амплитуде   составляющей,   аргумент   —   её   фазе.
Коэффициенту с номером k соответствует частота fk = k·fд / N; шаг по
частоте   Δf   =   fд   /   N   называют   разрешением   ДПФ.   Чем   длиннее
анализируемый фрагмент, тем мельче шаг: при fд = 16 кГц и N = 2048 он
равен   7,81   Гц.   Для   вещественного   сигнала   спектр   симметричен,   поэтому
достаточно первых N/2 + 1 коэффициентов, соответствующих частотам от 0
до   fд/2   (функции   numpy.fft.rfft   и   rfftfreq).   Чтобы   получить   амплитуду
синусоиды, модуль коэффициента умножают на 2/N.
Прямое   вычисление   ДПФ   требует   порядка   N²   операций.   Быстрое
преобразование   Фурье   (БПФ,   FFT)   —   алгоритм,   вычисляющий   тот   же
результат за N·log₂N операций. Для N = 4096 это в 340 раз быстрее. БПФ
наиболее   эффективно   при   N,   равном   степени   двойки,   хотя   современные
реализации работают с любой длиной.
ДПФ   неявно   предполагает,   что   фрагмент   периодически   повторяется.
Если в окно укладывается нецелое число периодов синусоиды, на стыках
повторений возникают разрывы, и энергия одной частоты «растекается» по
соседним   коэффициентам.   Это   явление   называют   растеканием   спектра
(утечкой,   spectral   leakage).   Для   его   ослабления   фрагмент   умножают   на
оконную функцию w[n], плавно спадающую к краям (рис. 3, а). Спектр окна
(рис.   3,   б)   характеризуется   шириной   главного   лепестка,   определяющей
разрешение близких частот, и уровнем боковых лепестков, определяющим
способность   обнаружить   слабую   составляющую   рядом   с   сильной.
Прямоугольное окно (отсутствие окна) имеет самый узкий главный лепесток,

1.7. Цифровые фильтры
Цифровой   фильтр   —   алгоритм,   который   изменяет   соотношение
частотных   составляющих   сигнала:   пропускает   одни   и   ослабляет   другие.
Линейный   стационарный   фильтр   полностью   описывается   импульсной
характеристикой h[n] — откликом на единичный импульс. Выходной сигнал
равен свёртке входного сигнала с импульсной характеристикой: y[n] = Σ
h[k]·x[n   −   k].   Свёртка   во   временной   области   соответствует   умножению
спектров:   Y(f)   =   H(f)·X(f).   Комплексная   функция   H(f)   —   частотная
характеристика фильтра; её модуль |H(f)| называют амплитудно-частотной
характеристикой (АЧХ), аргумент — фазочастотной (ФЧХ).
По   виду   АЧХ   различают   четыре   основных   типа   фильтров   (рис.   5):
фильтр   нижних   частот   (ФНЧ)   пропускает   частоты   ниже   частоты   среза;
фильтр верхних частот (ФВЧ) — выше частоты среза; полосовой фильтр
(ПФ) пропускает полосу между двумя частотами; режекторный фильтр (РФ)
подавляет полосу. Узкий режекторный фильтр, подавляющий одну частоту,
называют notch-фильтром; он применяется для удаления сетевой помехи 50

1.8. Шум, помехи и оценка качества обработки
Реальные записи содержат мешающие составляющие разной природы.

Качество   обработки   оценивают   количественно.   Если   известен
эталонный   чистый   сигнал   s[n]   (в   лабораторной   работе   он   синтезируется

показывает выигрыш алгоритма. Сегментный SNR вычисляется как среднее
значений SNR по кадрам и лучше согласуется с восприятием, так как не
позволяет громким участкам «перевесить» тихие. Для речи применяют и
перцептивные метрики (PESQ, STOI), моделирующие слух, а при отсутствии
эталона   —   субъективное   прослушивание   и   анализ   спектрограмм.   Важно
помнить,   что   максимальный   SNR   не   всегда   означает   лучшее   звучание:
агрессивное   шумоподавление   может   создавать   «музыкальный   шум»   —
хаотичные тональные призвуки, неприятные на слух.
1.9. Восприятие звука, мел-шкала и кепстральные признаки
Слух человека воспринимает частоту нелинейно: разница между 100 и
200 Гц воспринимается так же, как между 1000 и 2000 Гц, то есть восприятие
высоты близко к логарифмическому. Для моделирования этой особенности
используют мел-шкалу: m = 2595·lg(1 + f/700). До 1 кГц она почти линейна,
выше — логарифмична. Мел-спектрограмму получают, суммируя энергию
спектра с весами набора треугольных фильтров, равномерно расставленных
по мел-шкале (обычно 26–128 фильтров): в области низких частот фильтры
узкие, в области высоких — широкие.
Мел-частотные   кепстральные   коэффициенты   (MFCC)   —   наиболее
распространённые признаки в распознавании речи, дикторов и акустических
событий. Их вычисление включает: разбиение на кадры с окном; БПФ и
вычисление     спектра     мощности;     применение     мел-фильтров;
логарифмирование энергий; дискретное косинусное преобразование (DCT).
Логарифм   отражает   логарифмическое   восприятие   громкости,   а   DCT
декоррелирует   энергии   соседних   полос   и   концентрирует   информацию   об
огибающей   спектра   (тембре)   в   первых   12–20   коэффициентах.   Нулевой
коэффициент   пропорционален   логарифму   энергии   кадра.   Пример
вычисления MFCC «с нуля» приведён в разделе 3.11.
Помимо MFCC, при анализе звука используют спектральный центроид
(«центр тяжести» спектра, характеризующий яркость звука), спектральный
спад (частоту, ниже которой сосредоточено 85–95 % энергии), спектральный
поток   (меру   изменения   спектра   между   кадрами,   применяемую   для
обнаружения   начала   нот),   а   также   основной   тон   F0,   определяемый   по
автокорреляционной функции или по кепстру.

Библиотека soundfile — обёртка над C-библиотекой libsndfile. В отличие

а sd.wait() ожидает окончания операции.
import sounddevice as sd                  # запись и воспроизведение

sd.wait()                                 # ждём окончания записи

sd.wait()                                 # ждём окончания

лежат   в   диапазоне   от   −1   до   1.   Работа   с   sounddevice   не   обязательна:

import numpy as np                        # массивы и вычисления
from pathlib import Path                  # работа с путями
from scipy.io import wavfile              # чтение и запись WAV

fs = 16000                                # частота дискретизации, Гц
dur = 2.0                                 # длительность, с
t = np.arange(int(fs * dur)) / fs         # моменты отсчётов, с
Path("sounds").mkdir(exist_ok=True)       # каталог для файлов

tone = 0.5 * np.sin(2 * np.pi * 440 * t)  # тон «ля» первой октавы
chord = sum(np.sin(2 * np.pi * f * t)     # сумма трёх тонов
for f in (262, 330, 392)) / 3 # до-мажор, нормировка
f0, f1 = 100, 4000                        # границы ЛЧМ-сигнала, Гц
k = (f1 - f0) / dur                       # скорость роста частоты
chirp = 0.5 * np.sin(2 * np.pi * (f0 * t + k * t**2 / 2))  # ЛЧМ
rng = np.random.default_rng(19)           # генератор с seed
noise = 0.1 * rng.standard_normal(t.size) # белый гауссов шум
hum = 0.2 * np.sin(2 * np.pi * 50 * t)    # сетевая помеха 50 Гц
noisy = tone + noise + hum                # тон с помехами

def to_int16(x):                          # перевод в 16-битный PCM
x = np.clip(x, -1.0, 1.0)             # защита от переполнения
return np.round(x * 32767).astype(np.int16)  # масштаб и тип


signals = {"tone": tone, "chord": chord,  # словарь «имя - сигнал»
"chirp": chirp, "noisy": noisy}  # четыре тестовых файла
for name, x in signals.items():           # обходим сигналы
wavfile.write(f"sounds/{name}.wav", fs, to_int16(x))  # запись
peak = np.max(np.abs(x))              # пиковое значение
print(f"{name:6s}: {x.size} отсч., пик {peak:.3f}")  # отчёт
Мгновенная частота ЛЧМ-сигнала — производная фазы, делённая на 2π:
f(t) = f0 + k·t, поэтому фаза равна 2π(f0·t + k·t²/2), а не 2π·f(t)·t. Последняя
запись — типичная ошибка, при которой конечная частота оказывается вдвое
больше ожидаемой. Функция to_int16 ограничивает сигнал диапазоном [−1,
1]:   у   файла   noisy.wav   пик   равен   1,026,   и   без   вызова   np.clip   отсчёты,
превышающие   полную   шкалу,   превратились   бы   при   приведении   типа   в
отрицательные   значения.   Вывод   программы:   tone   —   пик   0,500,   chord   —
0,995, chirp — 0,500, noisy — 1,026.

import numpy as np                        # массивы и вычисления
from scipy import signal                  # обработка сигналов
from scipy.io import wavfile              # чтение и запись WAV

fs, data = wavfile.read("sounds/tone.wav")  # тон 440 Гц, A = 0,5
x = data / 32768.0                        # нормированный сигнал


def quantize(x, bits):                    # равномерное квантование
q = 2.0 ** (1 - bits)                 # шаг квантования
return np.round(x / q) * q            # округление к уровню


def snr_db(ref, test):                    # отношение сигнал/шум
err = test - ref                      # ошибка = шум
return 10 * np.log10(np.sum(ref**2) / np.sum(err**2))  # в дБ


for bits in (4, 6, 8, 10, 12):            # разные разрядности
y = quantize(x, bits)                 # квантованный сигнал
theory = 6.02 * bits + 1.76           # для полной шкалы
msg = f"{bits:2d} бит: SNR = {snr_db(x, y):5.1f} дБ"  # измерено
print(msg, f"(теория {theory:5.1f} дБ)")  # сравнение с формулой

fs, data = wavfile.read("sounds/chirp.wav")  # ЛЧМ 100...4000 Гц
c = data / 32768.0                        # нормированный сигнал
naive = c[::4]                            # прореживание без ФНЧ
poly = signal.resample_poly(c, up=1, down=4)  # с ФНЧ внутри
fs2 = fs // 4                             # новая частота 4000 Гц
print("новая частота:", fs2, "Гц")        # 4000 Гц
print("частота Найквиста:", fs2 / 2, "Гц")  # 2000 Гц
wavfile.write("sounds/chirp_naive.wav", fs2,  # с наложением
naive.astype(np.float32))   # float32 допустим в WAV
wavfile.write("sounds/chirp_poly.wav", fs2,  # без наложения
poly.astype(np.float32))    # запись результата

3.8. Спектральное вычитание широкополосного шума
Спектральное   вычитание   —   классический   метод   шумоподавления.
Сигнал переводится в частотно-временную область с помощью STFT. На
участке,   где   полезного   сигнала   нет   (в   паузе),   оценивается   средний
амплитудный   спектр   шума.   Затем   из   модуля   спектра   каждого   кадра
вычитается оценка шума, умноженная на коэффициент перевычитания α, а
получившиеся отрицательные значения заменяются малой долей β исходного
модуля   (спектральный   «пол»).   Фаза   сохраняется   исходной,   и   сигнал
восстанавливается обратным STFT.

5.2. Требования к программе
- Язык — Python 3.10 или выше; используются библиотеки главы 2.
Зависимости фиксируются в файле requirements.txt.
-   Код   разделён   на   модули:   ввод-вывод,   алгоритмы   обработки,

ключом --help выводит описание всех параметров.
- Программа корректно обрабатывает ошибки: отсутствующий файл,
неподдерживаемый   формат,   пустой   каталог,   недопустимое   значение
параметра (например, частота среза выше частоты Найквиста). Сообщения об
ошибках   понятны   пользователю,   аварийное   завершение   сопровождается
ненулевым кодом возврата.
- Перед записью результата выполняется проверка диапазона отсчётов;
перегрузка   устраняется   ограничением   или   нормализацией   с   выводом
предупреждения.
- Все результаты сохраняются в каталог --output: обработанные сигналы
(WAV), графики (PNG), таблица экспериментов (CSV) и текстовый отчёт о
параметрах сигнала. Имена файлов формируются из имени исходного файла

def load(path, mono=True):                # чтение WAV в float64
fs, data = wavfile.read(str(Path(path)))  # частота и отсчёты
x = data.astype(np.float64)           # в вещественный тип
if np.issubdtype(data.dtype, np.integer):  # целочисленный PCM
x /= np.iinfo(data.dtype).max     # к диапазону -1...1
if mono and x.ndim == 2:              # многоканальный файл
x = x.mean(axis=1)                # сведение в моно
return fs, x                          # частота и сигнал


def save(path, fs, x, bits=16):           # запись WAV с защитой
Path(path).parent.mkdir(parents=True, exist_ok=True)  # каталог
x = np.clip(x, -1.0, 1.0)             # защита от переполнения
if bits == 16:                        # 16-битный PCM
data = np.round(x * 32767).astype(np.int16)  # целые
else:                                 # иначе IEEE float
data = x.astype(np.float32)       # 32-битные вещественные
wavfile.write(str(path), fs, data)    # запись файла
return Path(path)                     # путь к результату


def db(x, ref=1.0):                       # амплитуда -> децибелы
return 20 * np.log10(np.abs(x) / ref + 1e-12)  # защита от log(0)


def rms_db(x):                            # уровень RMS в дБFS
return float(db(np.sqrt(np.mean(np.square(x)))))  # одно число


def snr_db(ref, test):                    # SNR относительно эталона
n = min(ref.size, test.size)          # общая длина
err = test[:n] - ref[:n]              # остаточная ошибка
p_err = np.sum(err ** 2) + 1e-20      # мощность ошибки
return float(10 * np.log10(np.sum(ref[:n] ** 2) / p_err))  # дБ


def frames(x, fs, flen=0.025, hop=0.010): # разбиение на кадры
n_len, n_hop = int(flen * fs), int(hop * fs)  # в отсчётах
if x.size < n_len:                    # сигнал короче кадра
x = np.pad(x, (0, n_len - x.size))  # дополняем нулями
n = 1 + (x.size - n_len) // n_hop     # число кадров
starts = n_hop * np.arange(n)[:, None]  # начала кадров
idx = np.arange(n_len)[None, :] + starts  # индексы отсчётов
return x[idx] * np.hamming(n_len)     # кадры с окном
